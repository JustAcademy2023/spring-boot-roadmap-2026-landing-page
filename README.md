# Spring Boot Developer Roadmap 2026: Boot Bakery Landing Page

A playful, responsive, single file landing page that turns the Spring Boot developer roadmap into a layered cake. Learners tap each layer, read what to study, tick off what they can explain, and watch their progress bar fill.

## Features

- Interactive seven layer skill cake with a saved progress tracker
- Stage explorer with topics, a hands on tip and a completion checkbox
- Six month plan slider
- Filterable cards for courses and guides, all fully clickable
- Sticky pill header, rich footer and responsive layout
- Palette of baby pink, white, brown and yellow
- Keyboard focus styles and reduced motion support
- No build step, no dependencies beyond Google Fonts

## Topics Covered

Core Java, Spring core and Boot, REST APIs, SQL, Hibernate, JPA, MongoDB, Spring Security, JWT, Spring Cloud, Kafka, Kubernetes basics, testing, Docker and CI, plus fresher and remote job guidance.

## Run Locally

Open `index.html` in any browser. No installation needed.

## Deploy on GitHub Pages

1. Push `index.html` and `README.md` to the repository root.
2. Open Settings, then Pages.
3. Under Source choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Your page goes live at `https://<username>.github.io/spring-boot-roadmap-2026-landing-page/`.

## Customise

Edit the `stages`, `months` and `res` arrays inside the script tag to change content or links. Colours live in the `:root` variables at the top of the stylesheet.
